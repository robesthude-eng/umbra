# Umbra 0.11.0 — перенос согласованного оформления

Основа: исходники из `umbra-modern.zip`, клиент 0.10.0 / versionCode 15.
Результат: Android-клиент 0.11.0 / versionCode 16. В архиве исходники; APK не собран.

## Изменения

| Область | Реализовано |
| --- | --- |
| Навигация | Три раздела: чаты, звонки, настройки. Сохранены прежние идентификаторы вкладок; старая вкладка групп открывает фильтр групп. |
| Диалоги | Общий список без отдельных тяжёлых карточек, аватары 52 dp, поиск по имени и тексту последнего сообщения, фильтры «Все / Личные / Группы», кнопка «Написать». Даты: время сегодня, «Вчера», число и месяц, год для старых сообщений. |
| Новый разговор | Нижний лист с выбором существующего собеседника или вводом @никнейма. Ошибка разрешения имени остаётся в форме, повторная отправка блокируется на время запроса. |
| Новая группа | Выбор собеседников по аватарам и флажкам, дополнительные участники по @никнеймам. При ошибке приглашения сохраняется ID уже созданной группы: повтор не создаёт ещё одну. |
| Настройки | Редактирование профиля и фото, выбор системной / светлой / тёмной темы, цвета обоев на Android 12+, размер текста сообщений 16–22 sp, уменьшение анимаций. Настройки хранятся на устройстве и применяются после перезапуска. |
| История звонков | Группировка по дням, отдельное обозначение пропущенных входящих, повторный вызов из истории, выбор собеседника для нового аудио- или видеозвонка. Длительность завершённых вызовов не выдумывается: её нет в текущей модели данных. |
| Звонок | Крупный аватар, подписанные кнопки микрофона / динамика / камеры, отдельная кнопка завершения, переключение камеры на локальном превью. Для широкого невысокого окна предусмотрена горизонтальная компоновка. |
| Переписка | Более спокойный фон и контрастные пузыри; последняя реплика серии имеет отдельный нижний угол. Системная палитра применяется к пузырям, подписям и иконкам. Размер текста действует на сообщения и ввод. |
| Статусы | При нормальном соединении под именем показано «Личный чат» или «Группа». Проблемы подключения обозначают соединение с сервером. Одна галочка означает подтверждённую отправку, без заявления о прочтении. |
| Движение и доступность | Короткое появление экранов, отключение собственных переходов и плавной прокрутки при уменьшении анимаций, статичная точка записи в этом режиме. Голосовая дорожка поддерживает действие перемотки через семантику доступности. |

## Структура

- `ui/MainShell.kt` — навигация, список чатов, поиск, фильтры и новый разговор.
- `ui/CallsTab.kt` — журнал и выбор собеседника для звонка.
- `ui/SettingsTab.kt` — профиль, оформление и существующие действия аккаунта.
- `ui/MainDialogs.kt` — создание группы и общий диалог ввода никнейма.
- `ui/UmbraComponents.kt` — заголовки, пустые состояния, аватар группы, переход экрана, форматирование даты.
- `data/session/UiPreferences.kt` — локальные настройки оформления через SharedPreferences и StateFlow.
- `ui/theme/Theme.kt` — общая светлая / тёмная палитра, динамическая палитра, текст сообщений и уменьшение анимаций.

Перенос выполнен на существующей версии Compose. Экспериментальные Expressive-зависимости и обновление BOM в этот этап не включены.
Протокол API, сервер, схема Room, очередь сообщений и CallEngine совпадают с исходным архивом.
Изменён слой отображения видеоповерхностей: локальная камера получает `setZOrderMediaOverlay(true)`.

## Выполненная проверка

- Сравнение файлов с исходным архивом: серверная часть, сетевой слой, Room, очередь отправки, проигрыватели и движок звонков не изменены.
- Просмотр обработчиков выбора чата, создания группы, повторного вызова, сохранения оформления, профиля, выхода и удаления аккаунта.
- Расчёт контраста текста на 101 точке каждого фирменного градиента. Минимальные отношения:

| Тема | Текст сообщения | Время и статус |
| --- | ---: | ---: |
| Светлая | 5,24:1 | 4,85:1 |
| Тёмная | 6,87:1 | 6,16:1 |

Это расчёт по цветам исходников. Динамические системные палитры и фактический рендеринг на устройстве отдельно не измерялись.

## Проверка сборки и устройства

В среде подготовки нет Android SDK и эмулятора. Попытка запустить Gradle wrapper командой `--version` завершилась до запуска Gradle:
`java: error while loading shared libraries: libjli.so: cannot open shared object file`.
Компиляция Kotlin, Android Lint, инструментальные тесты и визуальная проверка APK не выполнены. Статическая проверка исходников не заменяет эти этапы.

В среде с JDK 17 и Android SDK 35:

```bash
cd android
./gradlew assembleDebug lintDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

На устройстве нужно проверить:

1. Ширину 320/360 dp, горизонтальный экран и крупный системный шрифт: видимость текста, ввода и завершения звонка.
2. Обе темы, системную палитру Android 12+, перезапуск приложения после настройки, размер сообщений и режим уменьшения анимаций.
3. Поиск и фильтры, новый разговор, создание группы, приглашение с ошибкой и повтор без дублирования группы.
4. Сохранение черновика и позиции списка после переходов и поворота.
5. Входящий и исходящий звонки, разрешения, микрофон, динамик, обе камеры, групповую сетку и смену ориентации; локальное видео должно отображаться над удалённым.
6. Фото, видео, голосовые и отправку сообщений после изменения темы, включая ошибки сети.

Для обновления установленного приложения следует использовать тот же ключ подписи, что у предыдущей версии.

## Дополнения 0.12.0

- Фото и видео открываются с коротким fade/scale-переходом; настройка уменьшения анимаций отключает его.
- Активный звонок можно свернуть кнопкой или системной кнопкой «Назад». Компактная панель возвращает на экран звонка и позволяет завершить разговор.
- Дорожка голосового строится по PCM-сэмплам, декодированным из настоящего аудиофайла; результат кэшируется в памяти. Декоративный рисунок используется только до загрузки или при неподдерживаемом файле.
- Начиная с ширины 840 dp список чатов и выбранная переписка показываются рядом. Выбранная строка подсвечивается, а остальные разделы сохраняют полноэкранную компоновку.

## Дополнения 0.16.11

### Медиа в переписке

- Всё оформление фото и видео собрано в `ui/MediaKit.kt`: `AttachmentPhoto` строит кадр, `MediaBadge` — бейджи поверх него, `mediaScrim` — тень у нижней кромки, `Modifier.mediaSkeleton` — скелет загрузки.
- Ширина медиапузыря задана одной константой `MediaBubbleWidth`, пропорции ограничены `MEDIA_MIN_RATIO` и `MEDIA_MAX_RATIO`.
- Слишком вытянутые кадры показываются целиком (`ContentScale.Fit`), а фон собирается из размытой копии снимка — нет ни чёрных полей, ни обрезанных голов.
- Загрузка без скачков: размер известен до появления превью, поэтому лента не перестраивается; скелет заменил бесконечный кружок.
- Неудачная загрузка видна и обратима: текст «Превью не загрузилось» и кнопка «Повторить».
- Подписи на кадре читаются за счёт градиентной тени, а длительность видео вынесена в отдельный бейдж в верхнем углу.

### Свайпы и жесты

- `ui/SwipeActions.kt` даёт два компонента: `SwipeMessageActions` для сообщений и `SwipeActionRow` для строк списка.
- Свайп по сообщению: вправо — «Ответить», влево — «Переслать». Порог — 52 dp, предел — 86 dp.
- Свайп по строке чата: вправо — «Прочитано», влево — «Позвонить». Порог — 64 dp, предел — 108 dp.
- Действие, недоступное для элемента (нет непрочитанных, групповой чат, удалённое сообщение), не тянется вовсе — жест не обещает того, чего не сделает.
- Смещение и подсказки считаются внутри `graphicsLayer`, жест не вызывает рекомпозицию содержимого.
- На пороге срабатывает тактильный отклик, после отпускания содержимое возвращается пружиной; при «Меньше движения» — без анимации.
- Двойной тап по сообщению ставит ❤️, долгое нажатие по-прежнему открывает полное меню.
- Каждый свайп дублируется через `CustomAccessibilityAction`, поэтому действия доступны из TalkBack.
- Ошибка быстрого звонка из списка показывается плашкой `NoticeBar` над списком.

### Проверка жестов на устройстве

1. Свайп вправо и влево по своему и чужому сообщению, включая голосовые и медиа.
2. Прокрутка ленты во время начатого свайпа: вертикаль должна оставаться плавной.
3. Свайп по строке группы (звонка нет) и по чату без непрочитанных.
4. Фото 9:16, панорама и длинный скриншот — кадр вписан, подписи читаемы.
5. Авиарежим: скелет, затем ошибка и кнопка «Повторить».
6. TalkBack: для сообщения и строки чата доступны дополнительные действия.
