# Umbra 0.14.1 — проверка релиза

## Автоматические проверки

```bash
cd android
./gradlew assembleDebug lintDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

## Сценарии на двух устройствах

1. Получить личное и групповое сообщение при закрытом приложении; проверить счётчик непрочитанных и его сброс после открытия чата.
2. Найти старое сообщение поиском с разным регистром.
3. Отредактировать своё текстовое сообщение в пределах 15 минут; убедиться, что второй клиент показывает новый текст и пометку «изменено».
4. Попробовать изменить чужое сообщение и своё сообщение старше 15 минут — операция должна быть отклонена клиентом.
5. Удалить своё текстовое, голосовое и медиа-сообщение у всех; второй клиент должен показать «Сообщение удалено».
6. Поставить реакции с двух аккаунтов; повторная реакция одного аккаунта должна заменить его предыдущую реакцию.
7. Ответить из уведомления Android при закрытом процессе и проверить доставку после восстановления сети.
8. Проверить, что клиенты 0.13 продолжают получать обычные сообщения. Управляющие сообщения 0.14 требуют обновления всех устройств для корректного скрытия из ленты.

Редактирование, удаление и реакции реализованы управляющими непрозрачными конвертами через существующую очередь сообщений. Серверная схема и Room не меняются.
