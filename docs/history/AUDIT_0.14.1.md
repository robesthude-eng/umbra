# Umbra 0.14.1 — повторный аудит функций

Проверены все функции, добавленные в 0.12–0.14: медиапросмотр, сворачивание звонка, настоящая аудиоволна, планшетная компоновка, ответы, пересылка, подписи и множественный выбор медиа, Picture-in-Picture, непрочитанные, поиск, редактирование, удаление, реакции и быстрый ответ из уведомления.

## Результат

- 27 из 27 воспроизводимых статических и логических проверок пройдено.
- Android XML успешно разобран.
- Конфликтующих маркеров и структурно незакрытых Kotlin-конструкций нет.
- Архив проверяется командой `unzip -t` перед выдачей.
- Аудит можно повторить: `python3 scripts/audit-client-features.py`.

## Исправлено во время повторной проверки

1. PiP после заранее свёрнутого звонка теперь показывает видео, а не компактную панель.
2. В PiP скрыта кнопка переключения камеры.
3. Аудиоволна поддерживает PCM float и прекращает обработку при зависшем декодере.
4. Планшетный режим сохраняет состояние и черновики отдельно для каждого чата.
5. Последняя реплика корректно отражает редактирование, удаление и локальные медиа до загрузки.
6. Окончательно неотправленное редактирование, удаление или реакция откатываются локально и показывают ошибку синхронизации.
7. Быстрый ответ из уведомления не роняет процесс при недоступной сессии.
8. Исправлены непрочитанные для удалённых сообщений, пустой поиск и меню удалённого сообщения.

## Ограничение среды

Полная компиляция не выполнена: Gradle Wrapper не может скачать Gradle 8.9 с `services.gradle.org`, а Android SDK в среде отсутствует. Поэтому окончательный статус APK всё равно требует:

```bash
cd android
./gradlew assembleDebug lintDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

После сборки нужен прогон на двух устройствах, включая Android 8/9, Android 12 и Android 14/15, а также планшет шириной от 840 dp.
