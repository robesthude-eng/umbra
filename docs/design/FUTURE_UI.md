# Umbra 0.16.7 — Future UI

## Концепция

Future UI делает Umbra глубокой и живой, но не превращает переписку в демонстрацию эффектов. В списках нет тяжёлых шейдеров: фон рисуется двумя простыми Canvas-градиентами, а сообщения сохраняют дешёвый рендеринг.

## Визуальная система

- `UmbraVisualTokens` — семантические цвета фона, стекла, границы, ауры, успеха и предупреждения.
- `FutureBackdrop` — медленно движущаяся аура приложения.
- `GlassPanel` — контрастная полупрозрачная панель, не зависящая от поддержки backdrop blur.
- `rememberUmbraChatColors` — стабильная персональная палитра по ID чата.
- `futurePress` — пружинный отклик элемента без изменения layout.

## Реализованные поверхности

- общий фон приложения;

- анимированные счётчики реакций;

- пружинная посадка свежего сообщения;
- обратное закрытие медиапросмотра;
- динамический остров отправки и записи.
- Command Center с поиском чатов и быстрыми переходами;
- сочетание `Ctrl/⌘ + K` и кнопка быстрого доступа.
- нижняя контекстная карточка действий сообщения;
- интерактивное закрытие медиа вертикальным свайпом;
- стеклянная панель свёрнутого звонка.
- правая контекстная панель сообщения на планшете;
- жест вызова Command Center из верхней зоны;
- остров прогресса загрузки обновления.

## Доступность и производительность

- Reduced motion останавливает движение ауры и отключает существующие переходы.
- Контент не зависит от прозрачности: стеклянные панели имеют самостоятельный контрастный цвет.
- Canvas использует только два радиальных и один вертикальный градиент.
- Список сообщений не содержит постоянно работающих шейдеров на каждом элементе.
- Размер текста сообщений продолжает настраиваться в диапазоне 16–22 sp.

## Что остаётся на 0.16.1–0.16.2

- координатный shared transition от конкретной миниатюры;
- трансформация сообщения в карточку задачи после появления Tasks;
- подключение активного звонка и загрузки обновления к общему острову;
- командная строка и контекстная панель;
- полноценный проход TalkBack и проверка контраста на реальных устройствах.

## Обязательная проверка

```bash
cd android
./gradlew assembleDebug lintDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

Проверить тёмную, светлую и Dynamic Color темы, reduced motion, шрифт 22 sp, TalkBack, телефон и планшет от 840 dp.

## Motion Engine 0.16.5

- единые параметры длительности и пружинной физики;
- velocity-aware закрытие медиа;
- пружинный возврат отменённого жеста;
- ограниченное панорамирование увеличенной фотографии;
- морфинг состояний острова активности;
- обязательный reduced-motion fallback.

## Spatial Media 0.16.6

- медиапросмотр является overlay того же Compose-дерева, а не отдельным окном;
- источник перехода берётся из реальных `boundsInWindow` пузыря;
- scale, translation, alpha и corner radius синхронизированы общим progress;
- Predictive Back напрямую управляет progress закрытия;
- отменённый back-жест возвращается spring-анимацией;
- pan/zoom изображения и swipe-dismiss взаимоисключаются;
- skeleton загрузки учитывает reduced motion.

## Merge & Network Diagnostics 0.16.7

- сохранены tolerant ISO-time и независимая отправка очереди;
- ошибки REST различаются по HTTP-коду, этапу, DNS, timeout и TLS;
- WebSocket публикует безопасный статус, код ответа, retry и время соединения;
- настройки показывают канал онлайн и последнюю успешную синхронизацию;
- визуальная ветка Motion/Spatial объединена с сетевой без потери исправлений.
