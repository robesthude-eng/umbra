# Umbra Spatial Media 0.16.6

## Архитектура

`AttachmentViewerOverlay` находится в том же корневом `Box`, что и переписка. Перед открытием `MessageRow` сохраняет реальные границы пузыря через `boundsInWindow`; координаты нормализуются относительно корня чата. Отдельное окно `Dialog` больше не используется.

## Переход

Один progress синхронно управляет масштабом, X/Y-переносом, прозрачностью и радиусом скругления. При открытии поверхность выходит из исходного сообщения, при закрытии возвращается к нему. Если координаты недоступны, используется безопасный scale/fade fallback.

## Жесты

- вертикальный swipe-dismiss учитывает скорость и дистанцию;
- Predictive Back управляет тем же progress;
- отменённый back возвращается пружиной;
- при масштабе фото больше 1× dismiss-детектор отключается, освобождая жест для pan/zoom;
- reduced motion отключает декоративную интерполяцию.

## Загрузка

До готовности расшифрованного файла показывается skeleton фиксированного размера, поэтому layout не скачет.

## Проверка выпуска

Статический аудит проверяет overlay, координаты источника, отсутствие media `Dialog`, Predictive Back, арбитраж zoom/dismiss, skeleton и Android manifest. Для production-релиза всё ещё нужны настоящая Gradle-сборка и device QA.
