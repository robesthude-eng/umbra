# Темы и цвета Umbra 0.16.15

При новой установке Umbra открывается со стандартным интерфейсом. В разделе
**Настройки → Темы и оформление → Тема интерфейса** доступны три варианта:

| Тема | Поведение |
| --- | --- |
| Стандартная | Исходный интерфейс Umbra; тема по умолчанию; эффекты Alien выключены |
| Дымчатое стекло | Матовые панели и мягкие акценты; эффекты Alien выключены |
| Alien Interface | Космический фон, голографические акценты и отдельная настройка силы эффектов |

Выбор применяется сразу и сохраняется после перезапуска. При обновлении
ранее выбранная тема сохраняется; настройки не сбрасываются при каждом запуске.

## Отдельные параметры оформления

- **Цветовая схема:** как в системе, светлая или тёмная; работает во всех темах.
- **Цвет оформления:** цвета выбранной темы либо синий, бирюзовый, зелёный,
  янтарный или розовый акцент. Цвет используется для элементов управления,
  исходящих сообщений, визуальных акцентов и эффектов Alien.
- **Цвета обоев:** системная палитра Android 12+ для стандартной темы.
  При включении заменяет выбранный вручную акцент. Для возврата к ручному
  выбору выключите переключатель. В остальных темах этот флаг сохранён,
  но не влияет на их палитру.
- **Текст сообщений:** размер 16–22 sp с живым предпросмотром.
- **Уменьшить анимацию:** общий параметр для всех тем.
- **Эффекты Alien:** спокойные или полные; настройка появляется только внутри
  темы Alien. При её первом выборе включается спокойный вариант, в дальнейшем
  восстанавливается сохранённая сила. Чтобы отключить эффекты, выберите другую тему.

Цвет акцента, яркость, текст и анимация — общие сохраняемые настройки.
«Цвета темы» возвращает исходную палитру текущей темы. Ручной акцент и палитра
обоев не подменяются случайными персональными цветами отдельных чатов.

## Первый запуск

| Параметр | Начальное значение |
| --- | --- |
| Интерфейс | Стандартная тема |
| Цветовая схема | Как в системе |
| Цвет оформления | Цвета темы |
| Цвета обоев | Выключены |
| Размер сообщений | 16 sp |
| Уменьшение анимации | Выключено |
| Эффекты Alien | Выключены |

## Перенос настроек

Раньше Alien включался поверх стандартного стиля отдельным параметром. Новый
ключ `interface_theme` в `umbra_appearance` хранит самостоятельный выбор
`STANDARD`, `SMOKED_GLASS` или `ALIEN`.

| Прежнее состояние | После обновления |
| --- | --- |
| Настроек нет | Стандартная |
| Стандартный стиль, Alien выключен | Стандартная |
| Стандартный стиль с Alien CALM / FULL либо старый флаг Alien | Alien с сохранённой силой |
| Дымчатое стекло с любой сохранённой силой Alien | Дымчатое стекло; эффекты Alien выключены |
| Новый явный выбор Standard и сохранённая сила Alien | Стандартная; эффекты остаются выключенными после перезапуска |
| Неизвестное имя темы или акцента | Стандартная тема или исходный цвет соответственно |

`resolveAlienIntensity` разрешает эффекты только при выбранном `ALIEN`;
одного ненулевого `alien_intensity` больше недостаточно. Выбор сохраняется
отдельно от силы эффектов, поэтому возврат к стандартному интерфейсу устойчив
к перезапуску. Миграция не изменяет аккаунт, переписку или серверные данные.

## Изменённые компоненты

- `data/session/UiPreferences.kt` — три темы, акцент, миграция и эффективная сила Alien.
- `ui/SettingsAppearance.kt` — выбор темы, цветовой схемы и акцента, параметры эффектов.
- `ui/SettingsComponents.kt` — актуальное название темы в списке настроек.
- `ui/theme/Theme.kt` — применение выбранной темы и цвета ко всему дереву интерфейса.
- `ui/theme/AccentPalette.kt` — парные акценты для светлой и тёмной схемы,
  цвета сообщений и токены эффектов.
- `MainActivity.kt` — передача выбранного цвета в UmbraTheme.
- `androidTest/.../UiPreferencesTest.kt` — семь тестов сохранения и миграции настроек.

Основные Kotlin-пути находятся под `android/app/src/main/java/com/umbra/app/`.
Версия Android: **versionCode 38, versionName 0.16.15**.

## Выполненная проверка

- Существующий статический аудит исходников: **117/117**; ожидания версии
  обновлены на 0.16.15.
- Проверены десять пар основного акцента и текста на нём: минимальный
  вычисленный контраст **5,75:1**. Это проверка заданных цветов, не замер
  контраста всех элементов на экране Android.
- Сверены файлы с полным проектом 0.16.14: предыдущие изменения настроек
  сохранены; сервер, база и код обмена сообщениями не изменялись.
- Проверены целостность итогового ZIP и совпадение с рабочими файлами.

**Сборка APK, Android Lint, инструментальные тесты и визуальная проверка
на устройстве не выполнены.** В окружении недоступны рабочий Java
(`libjli.so` не найден), Android SDK и эмулятор. Аудит исходников не является
подтверждением компиляции или прохождения Android-тестов.

В среде с JDK 17 и Android SDK 35:

```bash
cd android
./gradlew assembleDebug assembleDebugAndroidTest lintDebug
./gradlew connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.umbra.app.data.UiPreferencesTest
```

На устройстве следует проверить новую установку, обновление с активным Alien
и стеклом, смену всех трёх тем, перезапуск после возврата к стандартной теме,
каждый цвет в обеих схемах, цвета обоев Android 12+, крупный системный шрифт
и сохранение остальных разделов настроек.
