# Результаты проверок Umbra 0.16.18

Основа — предоставленный полный архив 0.16.17, SHA-256:
`52b92d464a12be8b8943ebdc8494d6572b77502044aced034f9ee6c66a4f7cb8`.
Версия клиента 0.16.18, versionCode 41. Исходные файлы сохранены; это полный проект,
а не патч. Рабочий сервер не изменялся. Дата проверки: 14 сентября 2026.

## Изменения

Разрешённые номера, бюджеты отправки/подбора OTP, ticket выдачи; устройства,
отзыв сессий, срок жизни не более 90 дней; привязка push и уведомления о входе;
отдельное подтверждение удаления аккаунта. Android содержит соответствующие
экраны. Скрипт резервного копирования шифрует весь pg_dump, создаёт завершённый
файл атомарно и очищает неудачные временные копии. Добавлены проверки зависимостей
и секретов в CI, Dependabot, x/crypto v0.56.0, контроль SHA-256 Gradle wrapper.
Облачное шифрование 0.16.17 сохранено. Порядок обновления — SECURITY.md.

Локальные команды Go использовали -buildvcs=false: исходники получены ZIP-архивом.
Новые тесты проверяют cooldown, общие бюджеты после перевыдачи/успеха, очистку

привязку действия/ticket/сессии, неудачную доставку, политику номеров и удаление.

сессий и отказ запуска при неполной схеме. Лимит PostgreSQL выражен в 2160 часах,
чтобы переходы летнего времени не увеличивали 90-дневный срок.

## Границы проверки

PGlite не заменяет native PostgreSQL 16; native PostgreSQL предусмотрен в CI,
но локально полный набор его конкурентных сценариев не запускался. Бэкап-тест
использовал синтетический pg_dump и настоящие скрипт/шифратор. Полное восстановление
реальной базы с вложениями и ключами не проверено. Реальные Telegram/FCM,
SSH/firewall/TLS рабочего сервера и Android-устройства не тестировались. Android
Gradle-конфигурация была проверена до стадии разрешения зависимостей; безопасный
локальный HTTPS-переход не включал небезопасные протоколы и не отключал проверку
сертификатов. В среде также нет принятой лицензии/установленного platform-tools.

В ZIP нет истории Git: Gitleaks локально проверяет файлы, сканирование настоящей
истории предусмотрено в CI. Сборка androidTest, даже если успешна, не означает
исполнения инструментальных тестов на телефоне. Для установки поверх текущего
приложения требуется прежняя подпись; ключ подписи в архив не добавляется.

Сканеры не доказывают отсутствие всех возможных уязвимостей. Модель остаётся
облачной с ключами сервера, без E2EE; локальная Room/медиакэш не шифруются этим
изменением. Перед установкой обязательны миграция 016 и настройка AUTH_ALLOWED_PHONES.

Предупреждение уровня модуля относится к неиспользуемому OpenPGP из x/crypto:
[GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932). Пакет не импортируется
приложением, пути вызова сканер не обнаружил.
