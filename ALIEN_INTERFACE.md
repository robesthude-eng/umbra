# Umbra Alien Interface 0.16.9

## Включение

Настройки → Оформление → Alien Interface. Переключатель хранится локально в `umbra_appearance` и применяется без перезапуска. По умолчанию режим выключен.

## Система

- Quantum backdrop: один Canvas с аурами, орбитами и детерминированным звёздным полем.
- Holographic glass: семантические glass-токены и спектральная граница.
- Orbital navigation: выбранная вкладка окружена спокойным кольцом.
- Alien chat palette: глубокий фон, cyan/magenta glow и трёхцветные исходящие сообщения.
- Network state: медленный режим встроен в общую энергетическую палитру.

## Доступность и производительность

Reduced motion оставляет статичную композицию. Режим использует один Canvas-фон без bitmap, видео, датчиков и постоянных частиц в списках. При выключенном Alien Interface сохраняется прежний Future UI.
