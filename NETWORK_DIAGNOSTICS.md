# Umbra Network Diagnostics 0.16.7

## Зачем

Публичное скачивание `/app/latest.json` не доказывает доступность авторизованного REST и `/v1/ws`. Поэтому клиент больше не объединяет все сбои в фразу «нет связи».

## REST

`ChatRepository` помечает этап синхронизации: продление сессии, список чатов, загрузка истории, обработка сообщения и профиль аккаунта. Пользователь видит безопасную категорию и HTTP-код; стек остаётся в `DiagLog`.

Различаются: HTTP 401/403/404/409/429/5xx, DNS, connect/socket timeout, TLS, IOException, SerializationException и DateTimeException.

## WebSocket

`WebSocketClient.Diagnostics` содержит только технические метаданные: connected, attempt, retryInMs, HTTP-код, безопасную причину и время последнего подключения. Токен и сообщения не журналируются.

## UI

Красная плашка показывает конкретную REST-причину. «Медленный режим» означает, что WebSocket отключён, но REST-опрос продолжает работу. В настройках отображаются состояние онлайн-канала, retry и последняя успешная синхронизация.
